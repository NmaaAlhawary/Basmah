# بصمة · Basmah

Clickable mobile prototype (PWA) for Basmah, a platform to discover and develop children's talents. Jordan first.

- Arabic (RTL) with an English mode
- Static site: `index.html`, `styles.css`, `app.js` — no build step
- Run locally: `python3 -m http.server 5211`

Opportunities and competitions use real Jordanian organisations; Basmah is not partnered with them. Child profiles are illustrative examples.
Photos: Unsplash (`assets/photos/CREDITS.md`). Videos: Mixkit (`assets/media/CREDITS.md`).
